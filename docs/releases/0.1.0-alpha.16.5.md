# BG3 Mod Manager Redux 0.1.0-alpha.16.5

Alpha.16.5 focuses on safer load-order organization, per-order Override control, and clearer update and storage workflows.

## Highlights

- Organize Active, Inactive, and Override Mods with separators and one level of sub-separators. Collapse sections, move grouped mods, and use Undo/Redo across supported moves. Existing load orders receive a one-time choice for persistent separators and legacy lines; Redux keeps a pre-upgrade copy before changing an existing order.
- Opt saved load orders into their own Override PAK selection. Disabled PAKs move to a managed folder, with file validation and recovery for interrupted operations. Orders without this option retain the previous all-Overrides behavior.
- Manage supported native plugins through an existing YANML installation, with reviewed installation, updates, and removal of Redux-owned DLLs.
- Set local mod aliases and preview artwork, choose a managed Downloads folder, and limit retained previous PAK versions independently of downloaded archives.
- Find mod updates from the Mod Review menu. Verified Nexus replacements receive a small indicator and a named review finding linked to the mod page.
- Choose **Update & Back Up** during a Redux update to save the existing app installation, BG3 mod PAKs and previous versions, saved orders, and profile load-order files to a ZIP before restarting. Game saves are not included.

## Refined and fixed

- Refined separator rows, branch connectors, pane headers, column resizing, and the category/separator editor across themes.
- Kept the selected BG3 profile through Refresh and improved how **Current** follows a successful Sync while preserving named saved orders.
- Fixed several separator collapse, migration, and drag-placement regressions, including rejected Override-to-Active drops and moves between Inactive and Override Mods.
- Kept mod lists visible when changing an alias; restored filename-display toggles, category icons, and clearer column tooltips for provider and local dates.
- Improved diagnostics for duplicate UUIDs and remote thumbnail decoding.

See the [full changelog](../CHANGELOG.md) for the complete change list. Redux remains a public alpha; review the selected profile and order before syncing after an update.
