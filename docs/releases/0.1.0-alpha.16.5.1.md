# BG3 Mod Manager Redux 0.1.0-alpha.16.5.1

<!-- redux:no-announce -->

This hotfix restores load-order switching for players whose BG3 Mods folder is a Windows junction or symbolic link. Redux validates the linked folder's resolved location before moving Override PAKs and records that location in its recovery journal, so changing the link cannot silently redirect an interrupted switch.

- Move inactive Override PAKs back into Override Mods by dragging them or using the mod's right-click menu. When the pane is empty, drop a held Override onto Active Mods; Redux enables it in Override Mods and smoothly reveals the pane.
- Keep sub-separator mod numbers, names, and status icons indented together, and make nested context menus easier to enter with the pointer.
- Show the estimated Nexus API cost before a full mod update check. A linked mod can be checked individually from its context menu; results now distinguish verified updates from skipped or failed file checks. Prompts point to the exact Preferences controls for online information and Nexus API access.

This release includes the full [alpha.16.5](0.1.0-alpha.16.5.md) feature set.
