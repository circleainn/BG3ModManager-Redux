# BG3 Mod Manager Redux 0.1.0-alpha.16.6

Release candidate — not yet published.

Development resumed after a loss of local development history. This update brings together
recovered work, reviewed fixes, and maintenance improvements. Thank you for your patience during
the gap between updates.

## Added

- **Preferences > Backups:** create named snapshots inside Redux, browse their dates and versions,
  and restore an earlier or later saved state. Optional mod backups include BG3 PAKs, held Overrides,
  and profile load orders. Every restore creates a return snapshot first. Operations run while Redux
  is closed, verify file hashes, and retain recovery information if interrupted.
- **Backup shortcuts and styling:** open the Backups tab from Tools or Quick Access. External
  backup, restore, and recovery windows follow the current theme, text size, and icon preference,
  with matching progress indicators, buttons, and result messages.
- **Tools > Resolve Override Copies:** review exact file paths and content comparisons, choose
  which copy to keep, and retain backups with recovery for interrupted operations. Refresh can
  finish while duplicates await review.
- **Move to Separator:** move one mod or a selection into nested or collapsed separators in
  Active, Inactive, and Override Mods. Moves stay within the same pane and support Undo/Redo.
- **Automatic category controls:** clear or restore automatic assignments for current mods and
  hide or show built-in filters independently. Manual assignments and custom categories are preserved.

## Fixed

- Preserve the saved workspace and last verified game order when `modsettings.lsx` is locked,
  damaged, or incomplete. Recheck the reviewed file before Sync or empty-order recovery, and show
  an unavailable sync status until a complete read succeeds.
- Clear stale Script Extender version pins and cache settings when the selected game's updater
  configuration is removed. Preserve valid pins and retain prior settings when the file cannot
  be read.
- Keep the Status menu's text, icon, and color consistent with its current diagnostic state.
- Match Resolve Override Copies buttons to shared dialog icons and the icon-visibility preference.
- Reject archives without PAK files before mod-install review, with clearer guidance for loose
  texture archives. Load-order-only archives remain supported through the order-import workflow.
- Validate manual Nexus links as Baldur's Gate 3 project pages or numeric IDs, and preserve query
  parameters when opening browser links.
- Restore category preferences if saving a change fails.

## Changed

- Replace ImageSharp with SkiaSharp for artwork previews. Preserve supported image formats,
  transparency, custom artwork sizing, and photo orientation while rejecting oversized or
  incomplete images.
- Improve experimental Wine handling for Script Extender cache detection, NXM forwarding, and
  updater/restart launches. Add a native forwarding helper and distinguish Wine-prefix registration
  from Linux browser setup.

## Known limitations

- Snapshots do not include saved games or game-directory DLL/loose-texture mods. Native-install
  ownership records remain unchanged. Snapshot sources cannot contain symbolic links or junctions;
  restore requires the original external mod/order folder locations. See [Backups](../BACKUPS.md).
- Wine/Linux support remains experimental; real Wine/Wayland validation is outstanding.
- Move to Separator targets remain within the source pane.
- The original Vivid Landscape 4K PAK installation report remains under investigation. The clearer
  no-PAK error applies to loose-texture archives and does not establish that the PAK issue is fixed.
- Editor-mod backup compression can still delay cancellation while the current member is compressed.
