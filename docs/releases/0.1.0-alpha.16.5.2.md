# BG3 Mod Manager Redux 0.1.0-alpha.16.5.2

<!-- redux:no-announce -->

This silent hotfix lets packages with both direct game-file overrides and a normal load-order entry move into Active Mods. Pure Override PAKs continue to use Override Mods.

## Fixed

- Move mixed Override packages into Active Mods through drag-and-drop; keep pure Override PAKs in Override Mods.
- Switch load orders when the BG3 Mods folder is a Windows junction or symbolic link, with pinned-target validation and recovery for interrupted Override moves.
- Move inactive Override PAKs back into Override Mods by dragging them or using the mod's right-click menu. When the pane is empty, drop a held Override onto Active Mods; Redux enables it in Override Mods and smoothly reveals the pane.
- Keep sub-separator mod numbers, names, and status icons indented together, and make nested context menus easier to enter with the pointer.
- Show the estimated Nexus API cost before a full mod update check. A linked mod can be checked individually from its context menu; results distinguish verified updates from skipped or failed file checks. Prompts point to the exact Preferences controls for online information and Nexus API access.

This release includes the full [alpha.16.5](https://github.com/circleainn/BG3ModManager-Redux/releases/tag/v0.1.0-alpha.16.5) feature set.
