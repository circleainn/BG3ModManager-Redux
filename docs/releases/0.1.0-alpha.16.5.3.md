# BG3 Mod Manager Redux 0.1.0-alpha.16.5.3

<!-- redux:no-announce -->

This update keeps selected load-order positions stable during Sync and addresses several regressions reported after 16.5.

## Fixed

- Keep explicitly selected mods at their chosen positions when exporting. Automatically add only missing installed dependencies, and flag conflicting dependency metadata in the Sync review instead of silently moving a mod such as Community Framework.
- Stop right-click menu actions from multiplying when switching between mods and separators.
- Leave Redux open when a user declines to save on close, and complete shutdown when the window does close.
- Preserve a verified Nexus link when refreshed local metadata lacks an optional creator manifest. Change or remove the link only when a valid current manifest provides contradictory source information.
- Point Nexus API-key guidance to the correct Preferences section.
