# BG3 Mod Manager Redux 0.1.0-alpha.16.7.2

<!-- redux:no-announce -->

## Changes in 16.7.2

- Download Manager has an optional **Auto-install NXM downloads to Inactive Mods** checkbox. With it enabled, new PAK mods from Nexus links go straight to the inactive library. Updates, overrides, saves and game-folder packages stay in Downloads for review.
- Welcome Setup offers 11 starter sections with distinct icons and colors. Redux uses offline mod groups to place headings around existing mods and preserves custom sections and load order.
- Redux recognizes Norbyte’s official v33 Script Extender updater. Installing an identical copy succeeds without replacing the DLL or changing who manages it. Unidentified DWrite.dll files are labeled and left in place.

## Also included from 16.7.1

- The offline Load Order Advisor now covers 12,017 modules, including 1,391 additions. It recognizes updated dependencies, placement guidance, and Fade's Equipment Distribution AIO as satisfying the standalone FED requirement.
- Choose **What this mod changes...** for an installed mod to browse its files and supported Stats records. The inspector shows which fields come from a parent in the package.
- Preferences now explain which folders Redux reads. Install All also explains where new mods go and what happens to existing mods during an update.

### Fixes in 16.7.1

- Collection previews now show identical repeated downloads once. Conflicting entries identify the collection revision and file.
- Save Order As preserves Override selections and separator placement. Each mod pane remembers its column order and widths, including after hidden columns are restored.
- Refreshing Script Extender versions preserves the selected version or digest, including pins missing from the current list.
- Redux checks the Nexus project when reviewing a native archive whose DLL has the same path as another project's. Changed DLLs get a clearer status.

## Requirements

The portable Windows build uses .NET 8 Desktop Runtime, as 16.7 did. Microsoft ended support for this runtime on November 10, 2026. [Microsoft lifecycle](https://dotnet.microsoft.com/en-us/platform/support/policy/dotnet-core)

## Also included from 16.7


- **Interface language:** choose a language in **Preferences > General > Interface language**.
  Changes preview immediately; use Save to keep your selection.
- **Language selection during setup:** Welcome Setup lists languages by their native names so
  you can choose before following the walkthrough. The choice is kept even if setup is deferred.
- **Translated workflows:** language support covers navigation, Preferences and generated help,
  Script Extender options, dialogs and confirmations, installation reviews, download progress,
  retained-package descriptions, backup summaries, and the external backup/restore window.
- **Translated search:** find keyboard shortcuts and Quick Access commands using translated names.

### Fixes in 16.7

- Refresh the install action when package inspection changes its destination.

### Other changes in 16.7

- Keep interface language independent of themes, text size, and built-in or custom fonts.
  Preserve command styling, sorting, and saved layouts when changing language.
- Keep mod names, user content, paths, load orders, and date/number formatting unchanged.

## Known limitations

- Some diagnostic and external-provider messages remain in English. Missing translations fall back
  to English. Native-speaker wording review is ongoing; please report unclear or incorrect text.
- Snapshot scope is unchanged: saves and game-directory DLL/loose-texture mods are excluded;
  restore requires the original external folder locations, and symbolic links/junctions are not
  supported. See the [backup guide](https://github.com/circleainn/BG3ModManager-Redux/blob/main/docs/BACKUPS.md).
- Wine/Linux support remains experimental; real Wine/Wayland validation is outstanding.
- The original Vivid Landscape 4K PAK installation report remains under investigation.
- Editor-mod backup compression can delay cancellation while the current member is compressed.

This release also includes the fixes and backup features from 16.6 and 16.6.1. See the
[changelog](https://github.com/circleainn/BG3ModManager-Redux/blob/main/docs/CHANGELOG.md) for earlier changes.
