# BG3 Mod Manager Redux 0.1.0-alpha.16.7

Released October 23, 2026.

Redux now offers English, French, Spanish, Russian, and Simplified Chinese interface languages.
This is the first language-support release; corrections from native speakers are welcome.

## Added

- **Interface language:** choose a language in **Preferences > General > Interface language**.
  Changes preview immediately; use Save to keep your selection.
- **Language selection during setup:** Welcome Setup lists languages by their native names so
  you can choose before following the walkthrough. The choice is kept even if setup is deferred.
- **Translated workflows:** language support covers navigation, Preferences and generated help,
  Script Extender options, dialogs and confirmations, installation reviews, download progress,
  retained-package descriptions, backup summaries, and the external backup/restore window.
- **Translated search:** find keyboard shortcuts and Quick Access commands using translated names.

## Fixed

- Refresh the install action when package inspection changes its destination.

## Changed

- Keep interface language independent of themes, text size, and built-in or custom fonts.
  Preserve command styling, sorting, and saved layouts when changing language.
- Keep mod names, user content, paths, load orders, and date/number formatting unchanged.

## Known limitations

- Some diagnostic and external-provider messages remain in English. Missing translations fall back
  to English. Native-speaker wording review is ongoing; please report unclear or incorrect text.
- Snapshot scope is unchanged: saves and game-directory DLL/loose-texture mods are excluded;
  restore requires the original external folder locations, and symbolic links/junctions are not
  supported. See the [backup guide](https://github.com/circleainn/BG3ModManager-Redux/blob/main/docs/BACKUPS.md).
- Wine/Linux support remains experimental; real Wine/Wayland validation is outstanding.
- The original Vivid Landscape 4K PAK installation report remains under investigation.
- Editor-mod backup compression can delay cancellation while the current member is compressed.

This release also includes the fixes and backup features from 16.6 and 16.6.1. See the
[changelog](https://github.com/circleainn/BG3ModManager-Redux/blob/main/docs/CHANGELOG.md) for earlier changes.
