# BG3 Mod Manager Redux 0.1.0-alpha.16.4.3

This silent cumulative maintenance hotfix restores several workflows reported after alpha.16.4.2.

## Fixed

- Restore **Copy Order to Clipboard** and **Export Order As List** to the visible load-order actions menu.
- Keep manual Nexus and mod.io linking attached to the exact mod that was right-clicked, even if it moves between Active and Inactive Mods while verification is running.
- Stop UUID-like mod.io archive filenames from being mistaken for legacy Nexus download IDs and receiving unrelated metadata.
- Restore the last selected named load order when Redux starts instead of always selecting Current.
- Keep Nexus and mod.io credential fields synchronized when encrypted credentials finish loading after Preferences opens.
- Retry remote mod thumbnails after temporary download or decode failures instead of caching the failed image for the rest of the session.

## Confirmed behavior

- Expanded separators move only their header. Collapsed separators move their sealed section as a block.

This is a silent maintenance release. It is delivered through the normal updater, GitHub, and Nexus Mods channels without a release announcement.
