# BG3 Mod Manager Redux 0.1.0-alpha.16.5.5

<!-- redux:no-announce -->

This hotfix improves large archive installation, cancellation, package recovery, and saved organization.

## Fixed

- Read solid 7z archives sequentially, avoid repeated decompression during review and installation, and stop after the last needed entry.
- Install complete multipart PAK sets together, including companion files in backups, Override moves, and interrupted-install recovery.
- Let the Install All close button cancel work, interrupt LSLib LZ4 decoding (including solid PAKs), and finish cleanup before closing Redux.
- Make manual PAK extraction and ZIP backups cancellable while preserving existing files on failure. Reject unsafe paths, duplicate destination PAK names, malformed archived orders, and incomplete editor-mod backups.
- Keep partially installed hybrid native packages available for retry until their companion PAKs are installed. Preserve installed mods' Nexus source links after a partial failure or cancellation.
- Keep completed downloads available when checksum verification is canceled, and retain failed removals with Retry Delete after restart.
- Prevent Refresh and Download Manager removal from interrupting active installation or cleanup.
- Import archived Current load orders into the correct entry without overwriting another saved order, and ignore unrelated JSON metadata.
- Save pending organization changes before Refresh and restore Inactive and Override ordering on startup.
- Restore remembered window placement and explicit gradient/font preferences, including returning to theme defaults.
- Open links in update notes, Help, and What's New in the default browser.

## Changed

- Show the current import phase, Download Manager package counts, and local intake progress and results.
- Reuse verified archive inspections and protect package files from changes until installation finishes.
- Publish library scans in one batch and defer duplicate-package warnings until the main window is visible.

## Known limitations

- Editor-mod backup compression can still delay cancellation while the current member is being compressed.
