# BG3 Mod Manager Redux 0.1.0-alpha.16.5.4

This update protects saved orders that contain copied separators from older Redux builds and refreshes the startup screen.

- Keep copied pre-16.5 separators attached to their shared definition when reopening an order or recovering settings after a crash, while preserving each order's placement and collapsed members.
- Keep distinct local separator rows when older saved data gives them the same or a missing ID.

## Changed

- Give the startup screen a clearer layout, a visible loading step, and progress that stays with that step across themes.
